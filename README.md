## Программа курса

1. **Введение. Общие понятия машинного обучения** — виды МО (с учителем, без учителя, с подкреплением), классы задач, основные алгоритмы, место МО в ИИ.
2. **Цикл машинного обучения** — стадии МО, источники и типы данных, подготовка и предобработка данных, разбиение датасета, обучение и тестирование модели.
3. **Регрессионный анализ** — виды регрессии (линейная, полиномиальная, логистическая), МНК, метрики MSE, RMSE, MAE, MAPE, R².
4. **Алгоритмы классификации** — двоичный и многоклассовый классификаторы, log loss, матрица путаницы, AUC-ROC.
5. **Дерево решений** — алгоритмы ID3, C4.5, CART, CHAID; энтропия, прирост информации, индекс Джини; обрезка дерева.
6. **Ансамблевые методы** — стекинг, бэггинг, бустинг, случайный лес.
7. **Классификация на основе логистической регрессии** — уравнение ЛР, логистическая кривая.
8. **Основы нейронных сетей, сети прямого распространения** — модели Ходжкина–Хаксли, Маккалока–Питтса, перцептрон Розенблатта, функции активации, градиентный спуск, backpropagation, Softmax.
9. **Сети для обработки изображений** — свёрточные нейронные сети, свёртка, padding, striding, pooling, архитектура CNN, backpropagation для CNN.
10. **Архитектуры современных CNN** — LeNet-5, AlexNet, VGG, ResNet.
11. **Анализ временных рядов** — дискретизация, теорема Котельникова, операции над рядами, разложение на компоненты, экспоненциальное сглаживание.
12. **Сети для обработки последовательностей** — рекуррентные сети (RNN), архитектуры LSTM и GRU, BPTT.
13. **Трансформеры. Автокодировщики** — Encoder-Decoder, Seq2seq, трансформеры, основные принципы построения автокодировщиков.

## Практические работы

### Правила сдачи

- Реализация на **Python, C++ или Java**; обязательна реализация на Python со стандартными библиотеками.
- Разрешены вспомогательные библиотеки для математики и обработки данных.
- **Запрещено**: использовать готовые реализации архитектур, алгоритмов обучения (в т.ч. Autograd в PyTorch), автоматический препроцессинг; все метрики реализовывать самостоятельно.
- Для сдачи: показать работоспособность программы + ответить на теоретические вопросы.
- По одной из работ необходимо сделать **теоретический доклад**.
- Лабораторная работа 1 выполняется первой. Блоки 2–4 можно выполнять в любом порядке.
- Заимствование чужих работ → дополнительные задачи и вопросы.

## Формат домашних заданий

Реализация в **Google Colab** или **Jupyter Notebook**. Результаты хранятся в Google Colab или в репозитории GitHub (папка с ноутбуками). Ссылка передаётся преподавателю.

Каждая работа должна содержать следующие блоки:

1. Название и краткое описание метода (≤1 абзац)
2. Используемые библиотеки
3. Описание и демонстрация датасета (частичная распечатка)
4. Предварительная обработка датасета
5. Тепловая карта
6. Обучение модели
7. Прогнозы модели
8. Графики выходных результатов
